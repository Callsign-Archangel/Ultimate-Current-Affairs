Make Uploaded Questions Appear on Every Device (Netlify Cloud Sync)

Not Linked Yet

By default, browsers save data only on the device where you uploaded it. Connect a free Firebase Realtime Database URL (or JSONBin.io URL) below so that whenever you upload questions from your PC or run your Python script, every phone, tablet, and computer opening your Netlify website automatically loads all your questions!

Step 1: Paste Your Cloud Database URL

We automatically append /ca_database.json for Firebase Realtime Database URLs.

Step 2: 1-Click Netlify Ready index.html

Want every phone, tablet, or friend opening your Netlify link to automatically see all questions without typing the Cloud URL on their device?

1. Paste your Firebase Realtime DB URL on the left & click Save & Sync Now.
2. Click the button below to download a new index.html with your Cloud URL permanently baked inside.
3. Upload that index.html to Netlify once — done forever!
How to get a Free Firebase Realtime Database URL in 60 seconds:
  1. Go to console.firebase.google.com → Create a project → Click Build → Realtime Database → Create Database.
  2. Choose Start in Test Mode (or set Rules to ".read": true, ".write": true).
  3. Copy the database URL shown at the top (looks like https://my-ca-app-default-rtdb.firebaseio.com/) and paste it in Step 1 above!
  4. Alternative Static Method: You can also place ca_database.json in the same folder as index.html on Netlify — this website automatically fetches ./ca_database.json on every device load!

How Your append_ca_from_excel.py Cloud Workflow Works

  1. Keep your daily questions in an Excel file named current_affairs.xlsx.
  2. Run python append_ca_from_excel.py on your computer whenever you add new rows in Excel.
  3. The script automatically merges your new Excel rows into ca_database.json AND pushes them directly to your Cloud Database URL so your live Netlify website updates across all devices immediately!
